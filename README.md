# Roy - Sitio Web Oficial

Repositorio realizado para aprender a desarrollar con el framework [Astro](https://astro.build/), aprovechando su arquitectura orientada a contenido para lograr un rendimiento óptimo y de contenido estático.

Se desarrolla una página del músico solita Roy, proyecto en el cual formo parte de la banda. Se crea un diseño propio el cual busca ser simple y fácil de agregar/editar/quitar contenido.

## Características

- 🎵 **Discografía**: Explora los álbumes y pistas de Roy, con enlaces directos a plataformas de streaming como Spotify.
- 🎤 **Conciertos**: Mantente informado sobre próximas presentaciones y eventos en vivo.
- 📸 **Multimedia**: Navega por una galería de fotos y videos que capturan la esencia y evolución de la banda.
- 📝 **Biografía**: Conoce la historia, inspiraciones y logros de Roy.
- 🔗 **Integración con Redes Sociales**: Conecta con Roy en plataformas como Instagram, YouTube y Spotify para contenido adicional y actualizaciones.

## Tecnologías Utilizadas

- [Astro](https://astro.build/): Framework moderno para la creación de sitios web rápidos y estáticos.
- [Tailwind CSS](https://tailwindcss.com/): Framework de CSS para un diseño ágil y responsivo.
- [Astro Image](https://docs.astro.build/en/guides/images/): Optimización de imágenes.
